# Git Commands

## 1. git status

The `git status` command displays the current state of the Git working directory and shows files that are untracked, modified, or staged for the next commit.

## 2. git add

The `git add` command moves selected changes from the working directory to the staging area, allowing Git to include those changes in the next commit.

## 3. git commit

The `git commit` command records the staged changes in the local Git repository and creates a new entry in the project's version history.

## 4. git push

The `git push` command transfers committed changes from the local repository to a remote repository such as GitHub, updating the remote branch with the latest commits.

## Exit Ticket

### 1. Which Git area contains your next commit?

The next commit is stored in the staging area after using the `git add` command. Git uses the staging area to determine which changes will be included in the next commit.

### 2. What makes a commit message useful?

A useful commit message is short, clear, and describes the changes made in that commit. It helps developers understand the purpose of a change when reviewing the project's history.
